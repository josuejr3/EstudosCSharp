
<div><h1 align="center" style="color: #00ff00">Funções</h1></div>

-  Representam um processamento que possui um significado

	-  Math.Sqrt(double)
	-  Console.WriteLine(string)

-  Principais vantagens: modularização, delegação e reaproveitamento de códigos

-  Dados de entrada e saída

	-  Funções podem receber dados de entrada (parâmetros ou argumentos)
	-  Funções podem ou não retornar uma saída

-  Em orientação a objetos, funções em classes recebem o nome de "métodos"

-  Como a função main é uma função "static" qualquer outra função que for necessária ser usada na main também deve ser static.

> *Exemplo - Função*

```c#
static int Maior(int a, int b, int c){
	int m;
	if (a > b && a > c){
		m = a;
	}
	else if (b > c){
		m = b;
	}
	else{
		m = c;
	}
	return m;
}
```

Lembrando que no caso de funções "gerais", ou seja, as que não são métodos de uma classe, elas devem ser criadas no escopo entre a classe e a main.


<div><h1 align="center" style="color: #00ff00">Laço While</h1></div>

O laço While executa um bloco de código uma quantidade de vezes até que uma condição não seja mais verdadeira. 

-  Sempre que a condição for True - continua
-  Se a condição for False - termina

> *Exemplo - Laço While*

```c#
Console.Write("Digite um número: ");
double x = double.Parse(Console.ReadLine(), CultureInfo.InvariantCulture);

while (x >= 0){
	double raiz = Math.Sqrt(x);
	Console.WriteLine(raiz.ToString("F3", CultureInfo.InvariantCulture));
	Console.Write("Digite um número: ");
	x = double.Parse(Console.ReadLine(), CultureInfo.InvariantCulture);

}
Console.WriteLine("Número negativo");
```


<div><h1 align="center" style="color: #00ff00">Laço For</h1></div>

A estrutura for é composta por três elementos. O primeiro é início, de onde onde começa a repetição, a segunda é a condição para que a repetição ocorra, e po último o incremento que basicamente acrescenta mais um toda vez que uma repetição é feita.

Essa estrutura é usada para quando se conhece a quantidade de repetição é conhecida.

> *Exemplo - Laço For*

```C#
Console.Write("Quantos números inteiros você vai digitar? ");
int n = int.Parse(Console.ReadLine());
int sum = 0;
for (int i = 1; i <= n; i++){
    Console.Write($"Valor #{i}: ");
	int value = int.Parse(Console.ReadLine());
	sum += value;
}
Console.WriteLine($"Soma = {sum}");
```
