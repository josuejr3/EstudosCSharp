
<div><h1 align="center" style="color: #00ff00">Modificadores de Parâmetros</h1></div>

Modificadores de parâmetros praticamente alteramos os parâmetros de uma função, como o próprio nome já diz. Em um código de calculadora por exemplo poderíamos usar sobrecarga de funções para realizar somas entre, dois números, três, quatro e assim por diante. 

Entretanto, isso seria uma solução ruim, já que existem infinitos números.

```c#
class Calculator {
	public static int Sum(int n1, int n2){
		return n1+n2;
	}
	public static int Sum(int n1, int n2, int n3){
		return n1+n2+n3;
	}
	public static int Sum(int n1, int n2, int n3, int n4){
		return n1+n2+n3+n4;
	}
}
```

Poderíamos pensar numa solução passando um vetor e depois fazer a soma dos elementos do vetor. 

```c#
public static int Sum(int[] numbers){
	int sum = 0;
	for (int i =0; i < numbers.Length; i++){
		sum += numbers[i];
	}
	return sum;
}
```

Só que essa sintaxe na instaciação fica um pouco verboso de mais

```c#
int soma = Calculator.Sum(new int[] {2, 3});
```

Para resolver isso usamo um dos modificadores de parâmetros, o params.

<div><h3 style="color: #00ff00">Params</h3></div>
O modificador de parâmetros params basicamente compacta a sintaxe da "instanciação" de um vetor dentro do campo que recebe os argumentos da função (o params deve ser do mesmo tipo).

> *Exemplo - Uso do params*

Na função colocamos a palavra reservada *params*

```c#
public static int Sum(params int[] numbers){
	int sum = 0;
	for (int i = 0; i < numbers.Length; i++){
		sum += numbers[i];
	}
	return sum;
}
```

Enquanto que no programa principal não vai ser necessário instanciar o vetor ao chamar a função.

```c#
int soma = Calculator.Sum(2, 3, 4);
```

<div><h3 style="color: #00ff00">Ref e Out</h3></div>
Para enteder como o ref e o out funcionam vamos usar o exemplo da calculadora que estavamos vendo anteriormente. 

> *Exemplo - Função que triplica valores*

```c#
class Calculator{
	public static void Triple(int x){
		x = x * 3;
	}
}
```

```c#
class Program{
	static void Main(string[] args){
		int a = 10;
		Calculator.Triple(a);
		Console.WriteLine(a);
	}
}
```

Nesse caso ao rodarmos o código o valor de x não será retornado triplicado da função. Isso ocorre, pois como se trata de um tipo simples, um inteiro, ele é passado por valor, ou seja, é criada uma cópia do x ao invés de usar o próprio x.

Para resolver isso, basta passarmos o argumento como referência usando a palavra chave *ref*

```c#
class Calculator{
	public static void Triple(ref int x){
		x = x * 3;
	}
}
```

```c#
Calculator.Triple(ref a);
```

Aqui estamos alterando de fato a variável original passada como parâmetro.

---

O modificador out por sua vez, é similar ao ref (faz um parâmetro ser uma referência para a variável original), mas não exisge que a variável original seja iniciada. A palavra ref para ser usada exige por padrão que a variável seja iniciada.

> *Exemplo - Uso do Out*

```c#
class Calculator{
	public static void Triple(int origin, out int result){
		result = origin * 3;
	}
}
```

Nesse caso a função e triplicar passamos o valor que queremos triplicar e salvar ele em outra variável que passamos também como parâmetro da função. O resultado vai ser armazenado em *result*.

```c#
class Program{
	static void Main(string[] args){
		int a = 10;
		int triple;
		Calculator.Triple(a, out triple);
		Console.WriteLine(triple);
	}
}
```

Em resumo, o out é um parâmetro de saída de uma função.

Ambos os modificadores são considerados "code smells" (design ruim) e devem ser evitados.

<div><h1 align="center" style="color: #00ff00">Boxing e Unboxing</h1></div>

-  Boxing é o processo de conversão de um objeto tipo valor para um objeto tipo referência compatível

```c#
int x  = 20;
Object obj = x
```

Lembrando que o Object é um tipo referência, ou seja, um tipo classe. Quando atibuímos o x ao obj estamos fazendo um boxing, o x está virando um tipo referência.

-  Unboxing é o processo de conversão de um objeto tipo referência para um objeto tipo valor compatível.

```c#
int x = 20;
Object obj = x;
int y = (int) obj;
```


<div><h1 align="center" style="color: #00ff00">Listas</h1></div>

-  Listas são estruturas de dados com as seguites características
	-  Homogênea (dados do mesmo tipo)
	-  Ordenada (elementos acessados por meio de posições)
	-  Inicia vazia, e seus elementos são alocados sob demanda
	-  Cada element ocupa um "nó" (ou nodo) da lista
	-  Implementação encadeada

-  É implementada através da classe List ue vem das coleções
	-  Namespace: System.Collections.Generic

-  Vantagens:
	-  Tamanho variável
	-  Facilidade para realizar inserções e deleções

-  Desvantagens:
	-  Acesso sequencial aos elementos *

> *Exemplo - Instanciando Lista Vazia*

```c#
using System;
using System.Collections.Generic;
namespace Listas
{
    internal class Program
    {
        static void Main(string[] args)
        {
            List<string> list = new List<string>();
	        List<string> list2 = new List<string> {"Maria", "Alex" };
        }
    }
}
```

A classe de listas já fornece métodos prontos para trabalharmos com essas estruturas. Nós podemos:

-  Inserir elementos

		Add

Adiciona um elemento no final da lista

```c#
List<string> list = new List<string>();
list.Add("Maria");
list.Add("Alex");
```

		Insert

Esse método insere um elemento em uma posição específica da lista e desloca o restante

```c#
list.Insert(1, "José");
```

-  Tamanho da lista

		Count

Essa propriedade retorna o tamanho da lista, ou seja, a quantidade de elementos presente dentro dela.

```c#
Console.WriteLine(list.Count);
```

-  Encontrar o primeiro ou último elemento da lista que satisfaça um predicado

		list.Find

Predicados são como se fossem funções lambda em Python, passamos essas funções como argumento e essa função "roda" na lista.

```c#
// Encontrando a primeira ocorrência de um nome que começa com A
string s1 = list.Find(Test);
```

```c#
static bool Test(string s){
	return s[0] == 'A';
}
```

Dessa forma,  o Find chama a função Test que testa se cada valor da lista começa com A, a primeira vez que ele encontrar um valor ele faz o retorno.

Em resumo, o Find recebe uma função teste que podemos usar como expressão lambda.

```c#
string s1 = list.Find(x => x[0] == 'A');
```

		list.FindLast

O mesmo acontece para o findLast. Sendo que aqui, ele verifica todos os elementos da lista e só retorna o último elemento que começa com A.

```c#
string s2 = list.FindLast(x => x[0] == 'A');
```

-  Encontrar a primeira ou última posição de elemento da lista que satisfaça um predicado

		list.FindIndex

No caso desse método ele retorna  a posição do elemento desejado.

```c#
int pos1 = list.FindIndex(x => x[0] == 'A');
```

		list.FindLastIndex

```c#
int pos2 = list.FindLastIndex(x => x[0] == 'A');
```

-  Filtrar a lista com base em um predicado

		list.FindAll

Basicamente aqui filtramos a lista de forma que é criada uma nova que satisfaz o predicado que passamos.

```c#
List<string> resultado = list.FindAll(x => x.Length == 5);
```

-  Remover elementos da lista

		Remove

Espera como parâmetro uma string que é o elemento que vai ser removido.

```c#
list.Remove("Alex");
```
		
		RemoveAll

A remoção aqui é baseada em um predicado, que é uma função. 

```c#
// Removendo todo mundo que começa com 'M'
list.RemoveAll(x => x[0] == 'M');
```

		RemoveAt

Remove um elemento pela posição dele

```c#
list.RemoveAt(2);
```

		RemoveRange

Remove a partir de uma posição, uma quantidade de elementos

```c#
list.RemoveRange(2, 2);
```


<div><h1 align="center" style="color: #00ff00">Matrizes</h1></div>

Em programação, "matriz" é o nome dado a arranjos bidimensionais

-  Arranjo é uma estrutura de dados:
	-  Homogênea (dados de mesmo tipo)
	-  Ordenada (elementos acessados por meio de posições)
	-  Alocada de uma vez só, em um bloco contíguo de memória

-  Vantagens:
	-  Acesso imediato aos elementos pela sua posição
-  Desvantagens:
	-  Tamanho fixo
	-  Dificuldade para se realizar inserções e deleções

> *Exemplo - Instância e uma matriz 3x3*

```c#
using System;
namespace Matrizes{
    internal class Program{
        static void Main(string[] args){
            double[,] mat = new double[3, 3];
        }
    }
}
```

Matrizes possuem propriedades importantes, sendo elas:

-  Length

```c#
Console.WriteLine(mat.Length);
```

Quantidade de elementos dentro da matriz

-  Rank

```c#
Console.WriteLine(mat.Rank);
```

Quantidade de linhas

-  GetLength

```c#
Console.WriteLine(mat.GetLength(0));
```

Informa a dimensão zero da matriz tem tamanho dois.
