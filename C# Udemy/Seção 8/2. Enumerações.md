<div><h1 align="center" style="color: #00ff00">Enumerações</h1></div>

<div><h3 style="color: #00ff00">Definição</h3></div>

-  É um tipo especial que serve para especificar de forma literal um conjunto de constantes relacionadas

-  Palavra chave em C#: `enum`
		Nota: enum é um tipo de valor

-  Vantagem: melhor semântica, código mais legível e auxiliado pelo compilador

-  Referência: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/enum


>~={green} *Exemplo - Ciclo de Vida de Entidade*=~

Definindo uma classe para representar o pedido e uma enumeração para representar o status do pedido.

```c#
class Order {
	public int Id {get; set;}
	public DateTime Moment {get;set;}
	public OrderStatus Status {get;set;}
}

enum OrderStatus : int{
	PendingPayment = 0,
	Procesing = 1,
	Shipped = 2,
	Delivered = 3
}
```

Na main nós podemos instanciar, como também, converter um enum para string e vice versa.

```c
static void Main(string[] args)
{
	Order order = new Order
	{
		Id = 1000,
		Moment = DateTime.Now,
		Status = OrderStatus.PendingPayment,
	};
	Console.WriteLine(order);
	// Convertendo um enum para string
	string txt = OrderStatus.PendingPayment.ToString();
	Console.WriteLine(txt);
	// Fazendo o caminho inverso (string->enum)
	OrderStatus os = Enum.Parse<OrderStatus>("Delivered");
	// O valor deve estar igual ao que está dentro do enum OrderStatus
	Console.WriteLine(os);
}
```


<div><h3 style="color: #00ff00">Design</h3></div>

-  Em um sistema orientado a objetos, de modo geral "tudo" é objeto.

-  Por questões de design, tais como organização, flexibilidade, reuso, delegação, etc., há várias categorias de classes:

1.  Views - Telas
2.  Controllers - Meio de campo entre tela e o sistema
3.  Entities - Entidades de negócio
4.  Services - Representam serviços
5.  Repositories - Objetos responsáveis por acessar repositório de dados
