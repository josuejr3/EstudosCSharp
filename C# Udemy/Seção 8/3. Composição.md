<div><h1 align="center" style="color: #00ff00">Composição</h1></div>
-  É um tipo de associação que permite que um objeto contenha outro
-  Relação "tem-um" ou "tem-vários"
-  Vantagens:

	-  Organização: divisão de responsabilidades
	-  Coesão
	-  Flexibilidade
	-  Reuso

 Nota: embora o símbolo UML para composição (todo-parte) seja o diamanete preto, neste contexto estamos chamando de composição qualquer associação "tem-um" e "tem-vários".

-  A composição de objetos pode ser feita além de entidades, com serviços também.

> *~={green}Problema=~*

Ler os dados de um trabalhador com N contratos (N fornecido pelo usuário). Depois, solicitar do usuário um mês e mostrar qual foi o salário do funcionário nesse mês.


<div><h1 align="center" style="color: #00ff00">StringBuilder</h1></div>

O StringBuilder é uma classe responsável por montar strings de uma forma eficiente, sendo bastante usada em strings maiores.

-  O StringBuilder pertence ao namespace ``System.Text`` que é responsável por fazer manipulações em textos.
