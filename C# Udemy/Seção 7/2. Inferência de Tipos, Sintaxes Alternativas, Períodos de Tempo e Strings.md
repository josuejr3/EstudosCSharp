
<div><h1 align="center" style="color: #00ff00">Inferência de tipos: palavra var</h1></div>

Em C# a palavra reservada *"var"* serve para inferir tipos de variáveis, ou seja, não necessitando de informar o tipo, o compilador é que fará esse trabalho.

> *Exemplo - Uso do var*

```c#
var x = 10;
var y = 20.0;
```

Aqui, o compilador vai identificar a variável x como sendo um inteiro, mesmo que não tenhamos informado a ele.

<div><h1 align="center" style="color: #00ff00">Sintaxes Alternativas</h1></div>

<div><h3 style="color: #00ff00">Switch-Case</h3></div>

A estrutura switch-case é uma estrutura opcional a vários if-else encadeados, **quando a condição envolve o teste do valor de uma variável**.

> *Exemplo  - Uso do Switch-Case*

```c#
int x = int.Parse(Console.ReadLine());
string day;
	
switch (x){
	case 1:
		day = "Sunday";
		break;
	case 2:
		day = "Monday";
		break;
	//
	default:
		day = "...";
		break;
}
```

<div><h3 style="color: #00ff00">Expressão Condicional Ternária</h3></div>

Estrutura opcional ao if-else quando se deseja decidir um **VALOR** com base em uma condição.

> *Exemplo - Uso da condicional ternária*

```c#
double preco = double.Parse(Console.ReadLine(), CultureInfo.InvariantCulture);
double desconto = (preco < 20.0) ? preco * 0.1 : preco * 0.05;
```


<div><h1 align="center" style="color: #00ff00">Formatação de Strings</h1></div>

As strings em C# possui vários métodos que nos auxiliam a mexer com elas sendo eles:

-  Formatar

	-  ToLower()

```c#
string s1 = original.ToLower();
```

Tranforma tudo em minúscula

	-  ToUpper()

```c#
string s2 = original.ToUpper();
```

Transforma tudo em maiúscula

	-  Trim()

```c#
string s3 = original.Trim();
```

Remove espaços em branco antes e depois, é como se fosse um "strip" do Python.
-  Buscar
	-  IndexOf

```c#
int n1 = original.IndexOf("bc");
```

Descobre a primeira ocorrência de um caractere ou uma substring

	-  LastIndexOf

```c#
int n2 = original.LastIndexOf("bc");
```

Descobre a última ocorrência de um caractere ou uma subtring

-  Recortar
	-  Substring(inicio)

```c#
string s4 = original.Substring(3);
```

Corta a substring de uma posição até o final

	-  Substring(inicio, tamanho)

```c#
string s5 = original.Substring(3, 5);
```

Corta a substring a partir de uma posição e com uma quantidade limite de caracteres

-  Substituir
	-  Replace(char, char)

```c#
string s6 = original.Replace('a', 'x')
```

Troca um caractere por outro

	-  Replace(string, string)

```c#
string s7 = original.Replace("abc", "xy")
```

Troca todas as ocorrências de uma substring ou string por outra.

-  Verificação de Espaços e Vazia
	-  String.IsNullOrEmpty(str)

```c#
bool b1 = String.IsNullOrEmpty(original);
```

Verifica se uma string é vazia ou nula

	-  String.IsNullOrWhiteSpace(str)

```c#
bool b2 = String.IsNullOrWhiteSpace(original)
```

Verifica se uma string é nula ou um espaço em branco

-  Conversão para Números
	-  int.Parse(str)
	-  Convert.ToInt32(str)
-  Conversão de Numeros
	-  x.ToString()
	-  x.ToString("C")
	-  x.ToString("C3")
	-  x.ToString("F2")


<div><h1 align="center" style="color: #00ff00">DateTime</h1></div>

DateTime é um tipo valor do C# (struct), assim como int, float, double e entre outros. Ele representa um INSTANTE de tempo, isso quer dizer que ele serve para guardar uma data ou uma data e horário.

Nesse tópico nós vamos ver:
-  Representação Interna do DateTime
-  Instanciação: construtores, builders/conversão String -> DateTime
-  Formatação: DateTime -> String

1.  Um Objeto DateTime internamente armazena o número de "ticks" (100 nanosegundos) desde a meia noite do dia 1 de janeiro do ano 1 da era comum

> *Exemplo 1 - Uso do DateTime*

```c#
DateTime d1 = DateTime.Now; // Builder - horário atual do sistema
Console.WriteLine(d1);
Console.WriteLine(d1.Ticks);
```

2.  Existem outras formas de instanciar um objeto do tipo DateTime, tanto com construtores, como também com builders, vamos ver alguns exemplos.

> *Exemplo 2 - Somente Data*

```c#
DateTime d2 = new DateTime(2026, 02, 16);
```

> *Exemplo 3 - Data e Hora*

```c#
DateTime d3 = new DateTime(2026, 02, 16, 15, 30, 15);
```

> *Exemplo 4 - Data e Hora + milisegundos*

```c#
DateTime d4 = new DateTime(2026, 02, 16, 15, 30, 15, 500);
```

Porém, por padrão o DateTime não imprime os milisegundos, então da forma que está ele funciona, só não imprime. Para ajustar isso é preciso fazer uma formatação.

Existe ainda um parâmetro que pode ser colocado que se chama "DateTimeKind", ele serve para informar se o horário é local ou global.

A hora local tem o fuso horário (GMT). Se for uma data local o C# cria com o fuso horário da máquina.

> *Exemplo 5 - Dia e Hora atual*

```c#
DateTime d5 = DateTime.Today;
```

> *Exemplo 6 - Horário Atual no GMT*

```c#
DateTime d6 = DateTime.UtcNow;
```

3.  Conversão de strings para datas e vice-versa é semelhante ao de outras structs (tipos base).

> *Exemplo 7 - Convertendo uma Data qualquer para DateTime*

```c#
DateTime d7 = DateTime.Parse("2000-08-15");
```

O Parse aceita vários formatos de data e hora.

> *Exemplo 8 - Convertendo uma Data e Horário qualquer para DateTime*

```c#
DateTime d8 = DateTime.Parse("2000-08-15 13:05:58");
```

Outras formas de colocar data e horário também funcionam, como por exemplo, separar dia, mês e ano com barras.

> *Exemplo 9 - Uso do ParseExact para formatação personalizada*

```c#
DateTime d9 = DateTime.ParseExact("2000-08-15", "yyyy-MM-dd", CultureInfo.InvariantCulture);

DateTime d10 = DateTime.ParseExact("15/08/2000 13:05:58", "dd/MM/yyyy HH:mm:ss", CultureInfo.InvariantCulture)
```

Nesse caso além de passar a data devemos passar uma máscara de como a data deve ser formatada. Aqui, o CultureInfo.InvariantCulture é obrigatório.

> Referência: https://msdn.microsoft.com/en-us/library/system.datetime(v=vs,110).aspx

<div><h1 align="center" style="color: #00ff00">TimeSpan</h1></div>

O TimeSpan é outra forma de mexer com o tempo no C#. Entretanto, aqui ele representa uma **DURAÇÃO** ao invés de um instante, ou seja, um intervalo entre dois instantes.

Vamos ver:
-  Representação Interna
-  Instanciação: construtores, fields, métodos From e Parse.

1.  Um objeto TimeSpan internamente armazena uma duração na forma de ticks (100 nanosegundos). 

> *Exemplo - Uso do TimeSpan*

```c#
TimeSpan t1 = new TimeSpan(0, 1, 30); // Hora, Minuto e Segundo
Console.WriteLine(t1);
Console.WriteLine(t1.Ticks)
```

> *Exemplo 2 - TimeSpan com nenhum argumento*

```c#
TimeSpan t2 = new TimeSpan();
```

> *Exemplo 3 - TimeSpan passando quantidade de Ticks*

```c#
TimeSpan t3 = new TimeSpan(900000000L);
```

> *Exemplo 4 - Quantidade de Dias Horas Minutos e Segundos*

```c#
TimeSpan t4 = new TimeSpan(1, 2, 11, 21);
```

> *Exemplo 5 - Quantidade de Dias, Horas, Minutos, Segundos e Milisegundos*

```c#
TimeSpan t5 = new TimeSpan(1, 2, 11, 21, 400);
```

Além de usarmos construtores, podemos usar tambem os métodos "From" que considera dias, horas, milisegundos, minutos, segundos e ticks.

> *Exemplo 6 - TimeSpan de um dia e meio*

```c#
TimeSpan ts = TimeSpan.FromDays(1.5);
Console.WriteLine(ts);
```

> *Exemplo 7 - TimeSpan de uma hora e meia*

```c#
TimeSpan tss = TimeSpan.FromHours(1.5);
Console.WriteLine(tss);
```

Quase todos os métodos "From..." aceitam tanto números inteiros como float e double. No entanto, o método FromTicks só aceita números inteiros, já que ele é a menor unidade de tempo.

> Referência: https://msdn.microsoft.com/en-us/library/system.timespan(v=vs.110).aspx


<div><h1 align="center" style="color: #00ff00">Propriedades do DateTime</h1></div>

O tipo DateTime possui algumas propriedades que podemos obter para facilitar a manipulação dos dados.

A partir de um objeto DateTime nós conseguimos obter:

-  Date (DateTime)
-  Day (int)
-  DayOfWeek (DayOfWeek)
-  DayOfYear (int)
-  Hour (int)
-  Kind (DateTimeKind)
-  Millisecond (int)
-  Minute (int)
-  Month (int)
-  Second (int)
-  Ticks (long)
-  TimeOfDay (TimeSpan)
-  Year (int)

> *Exemplo - Propriedades*

```c#
DateTime d = new DateTime(2001, 8, 15, 13, 45, 58, 275);
Console.WriteLine($"Date: {d.Date}");
Console.WriteLine($"Day: {d.Day}");
Console.WriteLine($"DayOfWeek: {d.DayOfWeek}");
Console.WriteLine($"Hour: {d.Hour}");
Console.WriteLine($"Kind: {d.Kind}");
Console.WriteLine($"Millisecond: {d.Millisecond}");
Console.WriteLine($"Minute: {d.Minute}");
Console.WriteLine($"Month: {d.Month}");
Console.WriteLine($"Second: {d.Second}");
Console.WriteLine($"Ticks: {d.Ticks}");
Console.WriteLine($"TimeOfDay: {d.TimeOfDay}");
Console.WriteLine($"Year {d.Year}");
```

Além disso, existem vários métodos do tipo "To" que servem para exibir a data de forma diferente.

> *Exemplo - Imprimindo com outras formatações

```c#
Console.WriteLine(d.ToLongDateString());
Console.WriteLine(d.ToLongTimeString());
Console.WriteLine(d.ToShortDateString());
```

> *Exemplo - Criando uma máscara de formatação*

```c#
string s6 = d.ToString("yyyy-MM-dd HH:mm:ss");
```

Além de obter essa propriedades de uma data, nós podemos realizar operações com as datas como por exemplo, "adição" e "subtração" de datas.

> *Exemplo - Adicionando e Subtraindo Horas* 

```c#
Console.WriteLine(d.AddHours(2));
DateTime d1 = new DateTime(2000, 10, 15);
DateTime d2 = new DateTime(2000, 10, 18);
TimeSpan t = d2.Subtract(d1);
```


<div><h1 align="center" style="color: #00ff00">Propriedades do TimeSpan</h1></div>

Assim como o DateTime, o TimeSpan oferece várias propriedades e operações que nos auxiliam a mexer com intervalos de tempo.

-  TimeSpan.MaxValue

```c#
Console.WriteLine(TimeSpan.MaxValue)
```

-  TimeSpan.MinValue

```c#
Console.WriteLine(TimeSpan.MinValue)
```

-  TimeSpan.Zero

```c#
Console.WriteLine(TimeSpan.Zero)
```

-  Days

Retorna a quantidade de dias que tem dentro de um TimeSpan.

```c#
TimeSpan t = new TimeSpan(2, 3, 5, 7, 11);
Console.WriteLine(t.Days);
```

Além de Days, também existem o método para horas, minutos, segundos, milisegundos e ticks. E as propriedades "Total" que resume o total de cada uma das propriedades.

```c#
Console.WriteLine(t.TotalDays);
```

Ademais, o TimeSpan, semelhante ao DateTime, possui métodos de operações de soma e subtração, além de adicionais como multiplicação e divisão.

> *Exemplo - Soma de TimeSpan*

```c#
TimeSpan t1 = new TimeSpan(1, 30, 10);
TimeSpan t2 = new TimeSpan(0, 10, 5);

TimeSpan sum = t1.Add(t2);
TimeSpan dif = t1.Subtract(t2);
TimeSpan mult = t2.Multiply(2);
TimeSpan div = t2.Divide(2);

Console.WriteLine(sum);
Console.WriteLine(dif);
Console.WriteLine(mult);
Console.WriteLine(div);
```


<div><h1 align="center" style="color: #00ff00">DateTimeKind e padrão ISO 8601</h1></div>

O DateTimeKind é um tipo enumerado especial que define três valores possíveis para a localidade da data.

-  Local (fuso horário do sistema. Exemplo: São Paulo = GMT 3)
-  UTC (fuso horário GMT \[Greenwich Mean Time])
-  Unspecified

> **Boas práticas**

-  Uma boa prática de programação é armazenar em um formato UTC (texto: BD / JSON / XML)
-  Instanciar e mostrar em um formato local

Para converter um DateTime para Local ou UTC, podemos usar os seguintes métodos.

-  myDate.ToLocalTime()
-  myDate.ToUniversalTime()

```c#
Console.WriteLine($"data: {novaData}");
Console.WriteLine($"data kind: {novaData.Kind}");
Console.WriteLine($"data para local: {novaData.ToLocalTime()}");
Console.WriteLine($"data para utc: {novaData.ToUniversalTime()}");
```

No caso de datas com horário do tipo Unspecified ele tanto subtrai o valor, como também faz a soma.


<div><h3 style="color: #00ff00">Padrão ISO 8601</h3></div>

O Padrão 8601 é uma forma de representar datas e hora em sistemas computacionais, pode ser vista principalmente em bancos de dados.

-  Formato

```txt
yyyy-MM-ddTHH:mm:ssZ
```

O Z representa justamente o timezone UTC da data que está sendo manipulada.

```c#
DateTime d1 = DateTime.Parse("2000-08-15 13:05:58");
DateTime d2 = DateTime.Parse("2000-08-15T13:05:58Z"); // Escrito na forma 8601
```
