
<div><h1 align="center" style="color: #00ff00">Estrutura básica de um programa C#</h1></div>

1. Estrutura de Arquivos

	-  [ ]  Arquivo .sln
	-  [ ]  Arquivo .csproj
	-  [ ]  Classe principal .cs
	-  [ ]  Subpastas obj e bin

2. Program.cs

	-  [ ]  Cláusulas using: referências a outros namespaces
	-  [ ]  Namespace
	-  [ ]  Classe
	-  [ ]  Método
	-  [ ]  static void Main(string\[] args)

O projeto C# é uma solução, então ele vai ter um arquivo .sln que é o arquivo da solução e ele é que é responsável por abrir o projeto.

As subpastas obj e bin guardam os arquivos compilados.

A cláusula using funciona como se fosse o import do Python

O namespace não é obrigatório, porém, por questão de boa prática e organização os programas devem estar contidos em namespace.

Em relação a classe, normalmente colocamos o nome dela como sendo o mesmo nome do arquivo por questões de praticidade.

A declaração padrao da main é o ENTRY POINT da aplicação.
