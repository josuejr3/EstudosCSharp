
<div><h1 align="center" style="color: #00ff00">Tipos referência vs Tipos valor</h1></div>

<div><h3 style="color: #00ff00">Tipos Referência</h3></div>

Classes são tipos referência, ou seja, variáveis cujo tipo são classes não devem ser entendidas como caixas, mas sim, "tentáculos" (ponteiros) para caixas.

> Porque?

	Porque o que é armazenado em P1 é o endereço do objeto na memória.

```c#
Product p1, p2;
p1 = new Product("TV", 900.00, 0);
p2 = p1;
```

Nesse caso, quando eu faço a atribuição de p1 ao p2 significa que o p2 vai apontar para a mesma posição de memória que o p1.

Os tipos referência aceitam o valor *"null"*, que indica que a variável aponta para ninguém, igual temos em C/C++.

<div><h3 style="color: #00ff00">Tipos Valor</h3></div>

A linguagem C# possui também tipos valor, que são os "structs". Structs são **CAIXAS** e não ponteiros.

Os structs são os tipos base da linguagem, como o double. Quando variáveis double são criadas na stack de memória são criadas caixas que dentro delas vão ser armazenados números do tipo double.

> *Exemplo*

```c#
double x, y;
x = 10;
y = x;
```

Aqui o valor de x é de fato copiado para a variável y. Além dos tipos base, o tipo *DateTime* e o *TimeSpan* também são structs no C#.

É possível criar o meu próprio tipo valor. 

> *Exemplo - Criação de Struct*

```c#
namespace TiposValorEReferencia{
    struct Point{
        public double X;
        public double Y;
        public override string ToString(){
            return $"({X}, {Y})";
        }
    }
}
```

Veja que é semelhante a criação de uma classe Na main, instanciamos da seguinte forma.

```c#
static void Main(string[] args){
	Point p;
	p.X = 10;
	p.Y = 20;
	Console.WriteLine(p);
}
```

Perceba que não há necessidade de usar a palavra chave "new" pois a struct já aloca diretamente as caixinhas da struct, diferente da classe. 

-  O tipo struct aceita a palavra NEW, ele basicamente recria as caixinhas.

Sempre que alocamos qualquer tipo estruturado (classe, struct, array), são atribuídos valores padrão aos seus elementos

-  Números: 0
-  Bool: False
-  Char: caractere código 0
-  Objeto: null

<div><h1 align="center" style="color: #00ff00">Desalocação de Memória - Garbage Collector e Escopo Local</h1></div>

<div><h3 style="color: #00ff00">Garbage Collector</h3></div>

O Garbage Collector é um processo que automatiza o gerenciamento de memória de um programa em execução. 

Esse mecanismo monitora os objetos alocados dinamicamente pelo programa (no heap), desalocando aqueles que não estão mais sendo utilizados.

> *Exemplo - Desalocação com Garbage Collector*

Supondo o código abaixo.

```c#
Product p1, p2;
p1 = new Product("TV", 900.00, 0);
p2 = new Product("Mouse", 30.00, 0);
p1 = p2;
```

Inicialmente p1 aponta para um objeto específico, enquanto que o p2 também. Quando atribuímos ao p1 o p2, tanto o p1 como o p2 vão apontar para a mesma região na memória, que é o objeto "Mouse". 

Com isso, o objeto TV que estava sendo referenciado pelo p1 é desalocado automaticamente pelo Garbage Collector, pois ele não é referenciado por mais ninguém.

<div><h3 style="color: #00ff00">Desalocação por Escopo</h3></div>

Na desalocação por escopo, assim que um novo escopo é criado ele já aloca o espaço para a variável e assim que o bloco termina ela é desalocada.

```c#
void method1(){
	int x = 10;
	if (x > 0){
		int y = 20;
	}
	Console.WriteLine(x);
}
```

Nesse caso, primeiro é criado o escopo da função method1 e assim que ele é criado é alocado um espaço para a variável x. Em seguida vamos para o if, que constrói um outro escopo dentro do method1 e aloca diretamente espaço para variável y. 

Após sair do if, a variável y é desalocada automaticamente, assim como o x da função method1 quando a função em encerrada.

> *Exemplo - Meio de Caminho*

```c#
void method1(){
	Product p = method2();
	Console.WriteLine(p.Name);
}

Product method2(){
	Product prod = new Product("TV", 900.0, 0);
	return prod;
}
```

Aqui, primeiro a função method1 chama a função method2 que aponta para um objeto no heap. Essa função retorna o objeto para a method1 que está na stack. Dessa forma, o method1 vai referenciar direto um objeto no heap e o que foi criado com a method2 desaloca assim que o retorno do heap é feito para method1.

<div><h1 align="center" style="color: #00ff00">Nullable</h1></div>

O Nullable é um recurso do C# para que dados do tipo valor (structs) possam receber o valor null. 

Usos comuns:

-  Campos de banco de dados que podem valer nulo (data de nascimento, algum valor numérico, etc).
-  Dados e parâmetros opcionais.

O nullable pode ser escrito de duas formas no C#

```c#
Nullable<double> x = null;
```

```c#
double? x = null;
```

Dessa forma, dizemos que a variável x é opcional. É como se fosse uma variável que tem um *None* atribuída no Python.

Em resumo, nos códigos acima estamos dizendo que o x pode possuir um valor do tipo double ou então ser um null.

O nullable tem três operações básicas

-  GetValueOrDefault

```c#
Console.WriteLine(x.GetValueOrDefault());
```

Pega o valor da variável, no caso o x, ou então o valor padrão do tipo da variável.

-  HasValue

```c#
Console.WriteLine(x.HasValue);
```

Retorna um booleano informando se um valor foi atribuído a variável.

-  Value (lança uma exceção se não houver valor)

Nesse caso, lança uma exceção se está chamando através de uma variável nullable que tem como valor null.

```c#
Console.WriteLine(x.Value);
```

Para resolver isso, podemos usar um comando if.

```c#
if (x.HasValue){
	Console.WriteLine(x.Value)
} else {
	Console.WriteLine("X is null")
}
```

**Um nullable não pode ser atribuío para um struct comum**

<div><h3 style="color: #00ff00">Operador de coalescência nula</h3></div>

Esse operador consiste em duas interrogações (??). Ele é responsável por fazer atribuição de uma variável nullable para uma não nullable.

> *Exemplo - Uso do operador ??*

```c#
double? x = null;
double y = x ?? 0.0;
```

No exemplo acima, x é uma variável que pode ser nula e ela é nula. Na segunda linha estamos atribuindo uma variável nullable (x) para uma que não é (y). Isso poderia dar um erro. Para consertar, usamos o operador (??) que basicamente faz o seguinte.

Se x for um valor diferente de null, atribua ele a y. Se for diferente, atribua o valor 0.0 a variável.

> Referência: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-conditional-operator


<div><h1 align="center" style="color: #00ff00">Vetores</h1></div>

<div><h3 style="color: #00ff00">Vetores Armazenando Objetos do tipo Struct</h3></div>

Em programação, "vetor" é o nome dado a arranjos unidimensionais.

-  Arranjo é uma estrutura de dados:
	-  Homogênea (dados do mesmo tipo)
	-  Ordenada (elementos acessados por meio de posições)
	-  Alocada de uma vez só, em um bloco contíguo de memória

-  Vantagens:
	-  Acesso imediato aos elementos pela posição
-  Desvantagens
	-  Tamanho fixo
	-  Dificuldade para se realizar inserções e deleções

> *Exemplo - Criação de Vetor com base em um vaor n*

```c#
int n = int.Parse(Console.ReadLine()!);
double[] vect = new double[n];
```

Perceba que para informarmos que é um vetor, usamos os colchetes na região em que dizemos o tipo da variável.

<div><h3 style="color: #00ff00">Vetores Armazenando Objetos do tipo Classe</h3></div>

Nesse caso, além de criar o vetor que contém as "caixas" para cada elemento, também vai ser necessário criar cada um dos elementos em cada caixa correspondente.

> *Exemplo - Criação de Vetor para classes*

```c#
int n = int.Parse(Console.ReadLine());
Product[] vect = new Product[n];
double media = 0.0;
for (int i = 0; i < n; i++){
	string nome = Console.ReadLine();
	double preco = double.Parse(Console.ReadLine(), CultureInfo.InvariantCulture);
	vect[i] = new Product();
	vect[i].Name = nome;
	vect[i].Price = preco;
	media += vect[i].Price;
}
```

Nesse caso, além de usar o *new* para criar o vetor, ele também é usado para criar cada um dos elementos dos vetor dentro do próprio for.
