
<div><h1 align="center" style="color: #00ff00">Encapsulamento</h1></div>

Encapsulamento é considerado o primeiro pilar da orientação a objetos. Ele consiste em esconder detalhes de implementação de um componente, expondo apenas operações seguas e que o mantenha em um estado consistente.

-  O objeto deve sempre estar em um estado consistente, e a própria classe deve garantir isso.

> *1ª - Opção - Implementação Manual*

-  Todo atributo é definido como private (não vai ter acesso por outro arquivo)
-  Implementa-se métodos Get e Set para cada atributo, conforme regras de negócio
-  <span style="color:rgb(4, 255, 0)">Nota: não é usual na plataforma C#</span>

Vamos usar o projeto que tinhamos feito para produtos como exemplo.

```c#
private int _quantidade
```

Por convenção, na linguagem C# quando estamos trabalhando com atributos privativos, eles são escritos com underline seguido do nome todo em minúsculo.

Ok, mas da forma que está, como o atributo é privativo, não é possível acessar no método main. Para resolver isso, devemos criar métodos getters e setters.

> *Exemplo - Códigos Getters e Setters

```c#
public string GetNome(){
	return this._nome;
}
public void SetNome(string nome){
	_nome = nome;
}
```
