
<div><h1 align="center" style="color: #00ff00">Construtores</h1></div>

Um construtor é uma operação especial da classe, que executa no momento da instanciação do objeto, basicamente ele é o "criador" do objeto.

Ele inicia valores dos atributos e permite que um objeto receba dados/dependências no momento de sua instanciação.

-  Se um construtor customizado não for especificado, a classe disponibiliza o construtor padrão.

```c#
Produto p = new Produto();
```

-  Além disso, é possível especificar mais de um construtor na mesma classe fazendo o que chamamos de sobrecarga.

Quando instanciamos o objeto no formato acima, por padrão ele coloca todos os atributos internos como zeros ou nulo (null).

Não faz sentido criar um produto que não tem nome e nem preço. Dessa forma é importante que o programador defina já na inicialização do objeto um preço e um nome.

-  O construtor SEMPRE vai ter o nome da classe e nele podemos definir se ele vai ter um parâmetro de entrada.

> *Exemplo - Construtor customizado*

```c#
public class Produto
{
	public string Nome;
	public double Preco;
	public int Quantidade;
 
	public Produto(string nome, double preco, int quantidade)
	{
		Nome = nome;
		Preco = preco;
		Quantidade = quantidade;

	}
}	
```

Dessa forma, agora na função Main o construtor está obrigando a entrar com os dados da instância.

```c#
Produto p1 = new Produto("TV", 500, 10);
```


<div><h1 align="center" style="color: #00ff00">Sobrecarga</h1></div>

Sobrecarga é um recurso que uma classe possui de oferecer mais de uma operação com o mesmo nome, porém, com diferentes listas de parâmetros.

Basicamente é ter várias versões de construtores ou métodos variando apenas os parâmetros.

Em uma classe podemos ter várias versões de construtores, incluindo o padrão, podemos fazer o seguinte.

> *Exemplo - Vários construtores*

```c#
public Produto(string nome, double preco, int quantidade){
	Nome = nome;
	Preco = preco;
	Quantidade = quantidade;
}

public Produto(string nome, double preco){
	Nome = nome;
	Preco = preco;
	Quantidade = 0;
}
```

Se desejar o **construtor padrão** ele deve ser definido, uma vez que outros construtores já existem. Do contrário, ocorrerá um erro.

---

>  **Sintaxe alternativa para inicializar objetos**

A linguagem C# tem uma sintaxe alternativa/especial para inicializar objetos mesmo que elas não possuam construtores.

```c#
Produto p = new Produto (){
	Nome = "TV",
	Preco = 900.00,
	Quantidade = 0;
};
// Ou
Produto p = new Produto {
	Nome = "TV",
	Preco = 900.00,
	Quantidade = 0;
};
```


<div><h1 align="center" style="color: #00ff00">This</h1></div>

A palavra This é uma referência para o próprio objeto, assim como no C++ e como o self no Python.

Usos comuns:

-  Diferenciar atributos de variáveis locais (usado principalmente no Java);
-  Referenciar outro construtor em um construtor
-  Passar o próprio objeto como argumento na chamada de um método ou construtor.

> *Exemplo - Uso do This*

```c#
public Produto(string Nome, double Preco){
	this.Nome = Nome;
	this.Preco = Preco;
	Quantidade = 0;
}
```

Se o This não for informado, o compilador prioriza a variável local. No C# não é tão comum, pois os nomes dos parâmetros começam com letras minúsculas.

> *Exemplo - Usando o This para aproveitar construtores*

```c#
public Produto(){
	Quantidade = 0;
}
// Aproveitando o primeiro construtor
public Produto(string nome, double preco) : this() {
	Nome = nome;
	Preco = preco;
}
// Aproveitando o segundo construtor
public Produto(string nome, double preco, int quantidade) : this(nome, preco){
	Quantidade = quantidade;
}
```
