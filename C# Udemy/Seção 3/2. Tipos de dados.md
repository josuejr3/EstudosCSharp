#### Tipos valor pré-definidos em C\#

> Tipos Inteiros

Os primeiros oito tipos da tabela são para números inteiros a diferença entre eles vai ser somente a questão de ter ou não sinal e a quantidade de bytes que ele ocupa (ou seja até quanto ele pode "contar")

> Tipos de ponto flutuante

O números float e double são números quebrados ou seja número com casas decimais. O decimal é um número de 12 bytes é usado para cálculos de números muito grandes como cálculos financeiros de alta precisão.

> Tipos bool e char

O tipo char armazena um caracter unicode e possui a quantidade de dois bytes, enquanto que o tipo bool armazena um valor verdadeiro ou falso.

> Overflow

	O Overflow acontece quando um valor ultrapassa o valor da variável, ou seja, se colocarmos uma variável do tipo byte recebendo 300. Ela só pode receber até 255. Basicamente é quando estrapola o limite.

> *Exemplo - Uso do Long com identificador de tipo (L)*

```c#
long n4 = 2147483648L
Console.WriteLine(n4);
```

O mesmo vale para números do tipo float, é necessário indicar que ele é um float com a letra F. Do contrário o C# identifica como sendo um double.

```c#
float n5 = 4.5f;
```

#### Tipos referência pré-definidos em C\#

O tipo string não é considerado um tipo base da linguagem C#, assim como o tipo Object. 

> Tipo String

É uma cadeia de caracteres unicode **IMUTÁVEL** (segurança, simplicidade, thread safe)

> Tipo Object

É um objeto genérico (toda classe em C# é subclasse de object) GetType, Equals, GetHashCode, ToString.

#### Funções para valores mínimos e máximos

Os tipos númericos mínimos e máximos possuem valores mínimos e máximos e dentro do próprio tipo ele já informa isso. 

> *Exemplo - obtendo limites mínimos e máximos*

```c#
int n1 = int.MinValue;
```

#### Convenções de Nomes no C\#

-  Camel Case - lastName (parâmetros de métodos, variáveis dentro de métodos).
-  Pascal Case - LastName (namespaces, classes, properties e métodos)
-  Padrão - \_lastName (atributos "internos" da classe)

> *Exemplo - Convenções*

```c#
namespace Curso{
	class ContaBancaria{
		
		public string Titular { get; set; }
		private double _saldo;
		
		public void Deposito(double quantia){
			_saldo += quantia;
		}
		
		public double GetSaldo(){
			return _saldo;
		}
	}
}
```
