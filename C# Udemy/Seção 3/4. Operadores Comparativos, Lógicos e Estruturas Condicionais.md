Assim como em outras linguagens de programação o C# fornece operadores comparativos que vão ser essenciais para códigos de desvios de fluxo e laços de repetição. Abaixo são listados todos os operadores comparativos disponíveis na linguagem.

    <tr>
      <td align="center">&gt;</td>

      <td>a &gt; b</td>
      <td>true se a for maior que b</td>

> *Exemplo - Operadores comparativos*

```c#

bool c1 = a < 10;
bool c2 = a < 20;
bool c3 = a > 10;
bool c4 = a > 5;

Console.WriteLine(c1);
Console.WriteLine(c2);
Console.WriteLine(c3);
Console.WriteLine(c4);
```

<div><h1 align="center" style="color: #00ff00">Operadores Lógicos</h1></div>

Além dos operadores comparativos, outros operadores que o C# possui e que também existem em outras linguagens são os lógicos. Eles são responsáveis por verificar condições lógicas e retornar um verdadeiro ou falso.

<table border="1" align="center" cellpadding="8" cellspacing="0">
  <thead>
    <tr style="background-color:#000000;">
      <th align="center">Operador</th>
      <th align="center">Nome</th>
      <th align="center">Descrição</th>
      <th align="center">Exemplo em C#</th>
      <th align="center">Resultado</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td align="center">&&</td>
      <td>AND (E)</td>
      <td>Retorna true se ambas as expressões forem verdadeiras</td>
      <td>a &gt; 5 && b &lt; 10</td>
      <td>true se as duas condições forem verdadeiras</td>
    </tr>
    <tr>
      <td align="center">||</td>
      <td>OR (OU)</td>
      <td>Retorna true se pelo menos uma expressão for verdadeira</td>
      <td>a &gt; 5 || b &lt; 10</td>
      <td>true se uma das condições for verdadeira</td>
    </tr>
    <tr>
      <td align="center">!</td>
      <td>NOT (NÃO)</td>
      <td>Inverte o valor lógico da expressão</td>
      <td>!(a &gt; 5)</td>
      <td>true se a condição for falsa</td>
    </tr>
  </tbody>
</table>

> **NOTAS**

-  Precedência: ! > && > ||
-  Pode-se usar parênteses à vontade

> *Exemplo - Uso de operadores lógicos*

```c#
Console.WriteLine(3 > 5 && 2 == 1);
```


<div><h1 align="center" style="color: #00ff00">Estrutura Condicional</h1></div>

Estruturas condicionais são basicamente instruções que fazem o desvio de fluxo de dados ao longo da execução do programa e elas podem ser.

-  Simples - possuem somente o bloco if (_aqui as chaves são opcionais).
-  Composta - possuem o bloco if e o else
-  Encadeadas - possuem o bloco if else if e o else

> *Exemplo - Condição Simples*

```c#
int x = 10;
Console.WriteLine("Bom Dia");
if (x < 5){
	Console.WriteLine("Boa Tarde");
}
Console.WriteLine("Boa Noite");
```

> *Exemplo - Condição Composta*

```c#
int z = int.Parse(Console.ReadLine());
if (z % 2 == 0){
	Console.WriteLine("É par!");
}
else{
	Console.WriteLine("É ímpar!");
}
```

> *Exemplo - Condição Encadeada*

```c#
int h = int.Parse(Console.ReadLine());

if (h < 12){
	Console.WriteLine("Bom dia!");
} else if (h < 18 && h >= 12){
	Console.WriteLine("Boa Tarde!");
}
else{
	Console.WriteLine("Boa Noite!");
}
```
