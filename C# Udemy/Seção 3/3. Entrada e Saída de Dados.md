
<div><h1 align="center" style="color: #00ff00">Saída de Dados</h1></div>

Os comandos pra imprimir na saída padrão (console) são:

-  Console.WriteLine( valor );
-  Console.Write( valor );

A diferença entre os dois é que o primeiro coloca uma quebra de linha no final, enquanto que o outro não.

> *Exemplo - Imprimindo conteúdo de variáveis*

```c#
string nome = "João";
float numero = 4.5f;

Console.WriteLine(nome);
Console.WriteLine(numero.ToString("F2"))
```

O método "*ToString*" converte o valor float para uma string com a quantidade de casas decimais passadas como parâmetro.

Entretanto, quando a impressão ocorre percebe-se que o valor é exibido com o separado "," e podemos mudar para usar o separador ".".  Para isso, vamos usar também o método ToString, porém vamos precisar também do "*System.Globalization".

```c#
using System.Globalization;
// ...
Console.WriteLine(numero.ToString("F4", CultureInfo.InvariantCulture))
// ...
```

-  O InvariantCulture desconsidera qualquer formatação específica de país.

#### Placeholders, concatenação e interpolação

```c#
int idade = 32;
double saldo = 10.35784;
string nome = "Maria";
```

> *Exemplo - Placeholders*

```c#
Console.WriteLine("{0} tem {1} anos e tem saldo igual a {2} reais", nome, idade, saldo);
```

> *Exemplo - Interpolação*

```c#
Console.WriteLine($"{nome} tem {idade} anos e tem saldo igual a {saldo:F2} reais");
```

> *Exemplo - Concatenação de Strings*

```c#
Console.WriteLine(nome + " tem " + idade + " anos e tem saldo igual a " + saldo.ToString("F2", CultureInfo.InvariantCulture) + " reais");
```

A formatação com ponto só acontece diretamente com a concatenação de strings.

A concatenação não é exclusivamente de números, é possível fazer a concatenação cumulativa de strings.

Além desses operadores temos também os operadores de incremento e decremento

-  ++: incremente em um
-  \-\-: decrementa em um

> *Exemplo - pós incremento*

```c#
int a = 10;
int b = a++
```

A saída para esse caso é a valendo 11 e b valendo 10.

Isso ocorre porque primeiro o valor de a é jogado para a variável b e somente depois ele atualiza o valor de a para 11.

> *Exemplo - pré incremento*

```c#
int a = 10;
int b = ++a;
```

A saída para esse caso é a valendo 11 e b valendo 11.

Tanto a como b possuem os mesmos valores, primeiro é feito o incremento na variável a para só depois ser feito a atribuição de a em b.

<div><h1 align="center" style="color: #00ff00">Conversão Implícita e Casting</h1></div>

A conversão implícita entre tipos é quando um tipo pode ser naturalmente convertido para outro tipo. 

> Referências

https://docs.microsoft.com/pt-br/dotnet/csharp/language-reference/kewords/implicit-numeric-conversions-table

O casting já é uma conversão explícita entre tipos **compatíveis**

> *Exemplo - Conversão implícita de tipos*

```c#
float x = 4.5f;
double y = x;
```

Nesse caso, um float cabe perfeitamente dentro de um double. O contrário não é possível pois a informação é perdida já que está sendo feita a tentativa de colocar oito bytes num espaço de quatro.

Entretanto, se ainda sim for desejado é possível fazer a conversão explícita.

> *Exemplo - Conversão explícita*

```c#
double a;
float b;

a = 5.1;
b = (float)a;
```

Se um valor float ou double por exemplo for convertido para um inteiro a informação decimal é perdida. O mesmo acontece se formos executar uma operação de divisão, para isso é necessário que um dos operandos seja de ponto flutuante ou fazer o casting.

<div><h1 align="center" style="color: #00ff00">Entrada de Dados</h1></div>

O comando para obter um dado da entrada padrão, ou seja do teclado é o:

-  Console.ReadLine();

Ele lê da entrada padrão **até a quebra de linha** e retorna os dados lidos **na forma de string.**

Podemos então solicitar a entrada de três formas distintas.

1. Uma única frase em uma linha 

```c#
string frase = Console.WriteLine();
```

2.  Uma linha abaixo da outra

```C#
string x = Console.ReadLine();
string y = Console.ReadLine();
string z = Console.ReadLine();
```

3.  Várias palavras na mesma linha e usando o método "*Split*" para separar

```c#
string s = Console.ReadLine();
string[] vet = s.Split(' ');
```

Basicamente o método split vai criar separar a partir de espaços e cada um dos membros que compõe s vão ser colocados em posições do array vet.

```c#
string p1 = vet[0];
string p2 = vet[1];
string p3 = vet[2];
```

Uma forma alternativa de fazer a mesma coisa só que mais diretamente é assim

```c#
string[] v = Console.ReadLine().Split(' ');
```

4.  Lendo um número inteiro

Vimos que sempre que fazemos a leitura da entrada ela sempre é do tipo caractere ou string. Dessa forma, como podemos fazer para converter uma entrada de um conjunto de caracteres para um número de fato? basta fazer a conversão com o "Parse" que é um método do tipo int.

```c#
int n1 = int.Parse(Console.ReadLine());
```

Para conferir se o tipo foi realmente inteiro é possível printar usar o GetType().

```c#
Console.WriteLine(n1.GetType());
```

5.  Lendo um caractere

Da mesma forma que tivemos que fazer o Parse da string para inteiro, devemos fazer para quando se trata de um caractere.

```c#
char ch = char.Parse(Console.ReadLine());
```

6.  Lendo um número double

O double é praticamente igual aos dois anteriores, com a diferença de que ele utiliza a linguagem usada pelo computador, dessa forma, como o sistem operacional está em português o separador decimal é a vírgula e não o ponto.

```c#
double d = double.Parse(Console.ReadLine())
```

Para fazer a escrita com o ponto (igual estamos acostumados) devemos adicionar o Globalization que já tinhamos usado em outro código e dentro do Parse passamos o "*CultureInfo*.InvaritantCulture" como segundo parâmetro.

```c#
double d = double.Parse(Console.ReadLine(), CultureInfo.InvariantCulture)
```

7.  Lendo um nome (palavra única), sexo (caractere F ou M), idade (inteiro), e altura (double) na mesma linha, armazenando-os em quatro variáveis com os devidos tipos.

```c#
string[] data = Console.ReadLine().Split(' ');
string nome = data[0];
char sexo = char.Parse(data[1]);
int idade = int.Parse(data[2])
double altura = double.Parse(data[3], CultureInfo.InvariantCulture);
```
