
-  A Microsoft adotou como padrão para todos os projetos, o Java.
-  .NET é uma plataforma (ou ambiente de execução), ou seja, um conjunto de bibliotecas.
-  Permite que várias linguagens possam usar as mesmas bibliotecas.
-   A partir daí criou-se o C#. Além dela, o F# e o VB.net.
-  C# roda em outras plataformas.

> Exemplos de plataformas

1.  *.NET FRAMEWORK*
	Plataforma .NET que roda o C# apenas em Windows e serve para criar jogos, aplicações web e aplicações desktop.
	1.  WPF
	2.  Windows Forms
	3.  ASP.NET

2. *.NET CORE*
	Plataforma .NET que roda o C# em Windows, Linux e Mac, ele é multiplataforma e serve mais para aplicações Web.
	1.  UWP
	2.  ASP.NET Core

3.  *XAMARIN*
	Plataforma .NET que roda o C# em dispositivos mobile
	1.  iOS
	2.  Android
	3.  OS X

4. Mono
	Não é oficial, ele é multiplataforma e roda em tudo praticamente.
