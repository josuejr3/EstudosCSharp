<h1>📘 Estudos em C#</h1>

    </ul>

  <li>Coleções (<code>List</code>, <code>Dictionary</code>, etc.)</li>
  <li>LINQ</li>
  <li>Tratamento de exceções</li>
  <li>Manipulação de arquivos (I/O)</li>
  <li>Conceitos do .NET</li>
</ul>
